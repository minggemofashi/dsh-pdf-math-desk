# 数学课本工作区

用户会用**平常的话**下任务，不需要记任何编号。按意图直接做：不要先复述流程，不要列选项让用户选。

## 按意图分发

| 用户说的话像这样 | 当作 | 动手前先读 |
| --- | --- | --- |
| 提取 / 原文 / 抄一下 / 给我这几页 / 转成 LaTeX | **提取原文** | `规范/01_文本提取.md` |
| 为什么 / 怎么回事 / 这步怎么来的 / 看不懂 / 依据在哪 | **答疑** | `规范/02_答疑.md` |
| 做一下 / 解一下 / 答案 / 对一下 / 习题 | **做习题** | `规范/03_习题解答.md` |
| 其它：整理书库、拆书、查工具、改规范 | 直接办 | 按需读 |

判断规则：

- 只给了书名 + 页码、没说干什么 → **默认提取原文**，末尾只问一句「要不要顺带讲讲这段」。
- 一句话同时像答疑和习题（「这题为什么这样做」）→ 先讲原理，再给答案。
- 真判断不了，直接问一句，**不要列 1/2/3/4 选项**。
- `01`/`02`/`03`/`04` 仍可用，但只是可选别名，不必记。

## 硬规则（任何任务都适用）

1. **找书**：`工具\py.cmd 工具\pdfkit.py lookup <关键词> --chapter 4`（按章，首选）或 `--page 121`（按页）。
   **分片优先，分片没有才退回全本**。用户按章说事时用 `--chapter`，中文数字（四）也认；返回多本候选时补一个区分词（如「白皮书」）。
2. **页码是 PDF 物理页**（= 分片文件名里 `_97-138` 那种数字）。书上印刷页码可能差几页，交付时写 `物理 p.100（书页 92）`。
3. **公式**：行内 `$…$`；行间 `$$` 独占行。禁止 `\[` `\]` `\(` `\)`，也不用 `\begin{equation}` 之类环境。
4. 答疑和习题只在对话里输出，**不落文件**；提取输出**一个**代码块 + 三行以内说明。
5. 提取交付前必须跑 `pdfkit.py verify <文件> --tex`，拿到 `ok: true` 才算完。
6. 命令一律走 `工具\py.cmd`、`工具\node.cmd`（本机专用包装器，不进 git；别的机器用 `python`/`node` 直接跑）。
