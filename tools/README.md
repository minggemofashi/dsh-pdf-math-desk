# 数学书库拆分工具包

## 一、先说清楚：分片是干什么的

一本整书 PDF 几百页，直接丢给工作台会有两个问题：

1. **上下文太大**：一个会话如果总带着整本书，几轮就满了，还得不停开新会话；
2. **定位不清**：说“第四章这题”时，模型不知道第四章在书的哪一段。

「分片」就是把一本书**按章切成小 PDF**，一章一个文件（按需拆，不必一次拆完整本）：

- 每个会话只处理**一章**，上下文小、跑得久、回答也准；
- 章号写进文件名，工作台、会话标题、产物目录都用章号对位，不会串；
- 想复习哪章就打开哪章，不用在几百页里翻。

所以拆分不是给书“做备份”，而是给工作台**准备按章读取的原料**。工具（`pdfkit.py`）本身不识别内容、不做 OCR，**本质上只是按页范围切文件 + 按规则重命名**；真正的判断（哪页是第几章）由你来做，所以叫“手动拆分”。

**两条硬要求：**

1. **先手动拆——按章节拆**：一章一个 PDF（每章从哪页到哪页，看目录确定），目录页保留在 `c00`；工具不替你判断内容，**也不建议整本拆**（整本拆等于整本 OCR，又贵又容易撑爆上下文）。工具在这里的角色是**按规则重命名 + 校验**，帮你把名字和目录结构做规范。
2. **目录必须有**——书前面的目录页（以及封面/前言，如果有）请至少在 `c00` 里保留；目录是定位“第几章从哪页开始”的索引，只有几页，成本很低。没有目录，后面按章拆分和提问都会很费劲。

> 工作台的默认用法：**你手动拆出要学的章 → 工具重命名/校验 → 工作台按章读取**。想一次性拿到全书文本（如全书检索）是另一个任务，按整本 OCR 的成本单独评估。

## 二、目录结构

```
<库根>\
  分片\
    概率论\
      概率论_c00_前置_封面目录记号_p001-008.pdf
      概率论_c01_第一章_概率空间和随机事件_p009-040.pdf
      概率论_c02_第二章_随机变量及其分布_p041-068.pdf
      概率论_c04_第四章_积分和数学期望_p097-138.pdf
      ...
  # 以下可选
  产物\            # 会话产出的文件，工作台按 <书 id>\<章号>\ 读取
  封面\            # 自定义封面：<书 id>.png / .jpg / .webp
  索引.json        # 手写索引（可选；没有时工作台按文件名推导）
```

**书 id** 是「分片」下一级目录名（如 `概率论`、`Algebra_Lang`、`卓里奇数分一`）。工作台用它显示书架、拼会话标题 `[概率论 c04] 答疑`、对应 `产物\` 目录。取个短、稳的名字，别改来改去。

## 三、分片文件名规则

**编号可以省略。** 切分工具通常会在文件名末尾自动带页码（如 `概率论_积分和数学期望_97-138.pdf`）；
工作台会按页码顺序自动编号：目录/前言归 `c00`，正文按页序 `c01…`，附录归 `c90+`。
显式写成 `_cNN_` 的格式也支持。下面是显式格式：

```
<书 id>_c<章号>_第<X>章_<章名>_p<起>-<止>.pdf
```

- 章号固定两位：`c01`…`c99`；
- 特殊章号：`c00` = 前置（封面/目录/前言），`c90`/`c91` = 附录，`c99` = 参考书目/索引；
- `p起-止` 是**原书页码**，可以省略（没有页码的书）；有就写，方便 `resolve` 反查；
- 章名里的下划线会被工作台还原成空格；
- 一个 `分片\<书 id>\` 目录 = 一本书；同一本书不要拆到两个目录。

## 四、怎么拆（手动）

**推荐流程：先按章节手动拆，再改名。** 你按目录确定每章的页范围，用任意 PDF 工具（或 `pdfkit.py split`）**一章一个 PDF** 切出来；然后把切好的 PDF 放进 `分片\<书 id>\`，按下面的规则命名（`rename_chapters.py` 就是批量做这一步）。**不需要一次拆完整本书**；以后要学新章再加分片即可。

1. **找书、看页码**

   ```bat
   py pdfkit.py lookup 概率论 --chapter 4
   py pdfkit.py lookup 高等代数 谢启鸿 --page 120
   ```

   `lookup` 会在书库的整本 PDF 里定位，并告诉你第 4 章大概从哪页开始。

2. **按章切**（`--ranges` 一章一段，`--titles` 一一对应，**含 c00 前置**）

   ```bat
   py pdfkit.py split "D:\书\概率论.pdf" --ranges 1-8,9-40,41-68,69-96,97-138 ^
       --titles "前置,第一章 概率空间和随机事件,第二章 随机变量及其分布,第三章 随机向量和独立性,第四章 积分和数学期望" ^
       --out "D:\数学书库\分片\概率论" --prefix 概率论
   ```

3. **不知道章从哪页开始时**，让工具先识别：

   ```bat
   py auto_chapters.py "D:\书\概率论.pdf" --dry-run   # 先看识别结果
   py auto_chapters.py "D:\书\概率论.pdf" --out "…\分片\概率论" --prefix 概率论
   ```

4. **已经切好、只是名字不对**（本质就是重命名）：

   ```bat
   py rename_chapters.py "…\分片\概率论" --table 章表.txt
   ```

5. **校验**

   ```bat
   py pdfkit.py verify "…\分片\概率论\概率论_c04_第四章_积分和数学期望_p097-138.pdf"
   py pdfkit.py resolve "…\分片\概率论" --page 120   # 原书第 120 页落在哪个分片
   ```

6. **渲染封面**（可选；工作台也会自动渲首页，放 `封面\<书 id>.png` 可覆盖）

   ```bat
   py pdfkit.py render "…\分片\概率论\概率论_c00_前置_封面目录记号_p001-008.pdf" --pages 1 --out "…\封面\概率论.png"
   ```

## 五、不想拆？整本 PDF 也能读

如果实在不会/不想拆，把整本 PDF 直接放进 `<库根>\整本\`（**文件名就是书 id**，如 `整本\概率论.pdf`）——也可以直接放在库根（工作台只认 `.pdf`，不会和 `分片\` 冲突）：

- 书架会多出一张「整本 PDF」卡片，点开就是**整本阅读**（pdf.js，单页/连续、缩放、跳页都可用）；
- 代价：**没有分章、没有按章会话**，章号定位、`产物\<书 id>\<cNN>\`、按章提问这些都用不上；
- 之后想升级成分章版，按第三节补一个 `分片\<书 id>\` 目录即可，整本不会互相干扰。

## 六、加入工作台

1. 打开工作台 → 面包屑「书库」；
2. 点「选择目录」，选中**库根**（就是上面 `<库根>` 那层，里面应当有 `分片\`）；
3. 起个名字 → 「添加书库」；它会自动成为当前书库；
4. 双击这个书库条目 → 进入书架，按文件名列出书与章。

## 七、注意

- 工作台**只支持数学布局**（书名 / 章 / 三种会话：提取、答疑、习题）。
- 工作台**不会改你的书库**：不写 PDF、不建目录（只有 `产物\`、`封面\` 是它自己的），`索引.json` 存在时优先读，没有就按文件名推导。
- 某本书识别不出来时，先看页脚「跳过/未按章命名」清单，再对照第三节检查文件名。
- 工作台需要 Python（含 Pillow）才能跑 `pdfkit.py`；没有的话也可以手动切、手动改名——规则不变。
