# 03 任务③：习题解答

先读 `00_共同约定.md`（公式与输出规范）。本文件只讲流程。

**默认只给最终答案。** 要过程，你追问一句，我才展开。

---

## 第 1 步 把题目找对

页码或题号 → 渲页读图，**完整抄出题干**：

```powershell
$根 = "D:\数学书库"
& "$根\工具\py.cmd" "$根\工具\pdfkit.py" render "<PDF>" --pages 88 --bands 2 --dpi 220
```

抄题干时最容易丢的、必须核对的三样：

1. **区间与端点**（开区间还是闭区间、是否含端点）；
2. **初始条件 / 约束**（$f(0)=1$、$x>0$、$n \in \mathbb{N}^*$）；
3. **问的是全部解、还是某一个、还是证明存在性**。

题号必须和书一致（`习题 4.2 第 3 题`），题干里有 `⍰` 就说明它影响不了答案，还是必须点出来。

## 第 2 步 作答

先自己在草稿里解一遍并**代入验算**（把答案代回原式、检查定义域、检查端点），再输出。

### 默认形态：只有答案

一题一行，题号对齐，不写任何推导：

```
习题 4.2

1. $x = 2$
2. $y' = 3x^2 - 3$，驻点 $x = \pm 1$
3. 存在，$\xi = \tfrac{1}{2}$
4. 最大值 $4$（$x=2$ 处），最小值 $0$（$x=0$ 处）
5. 收敛，和为 $\dfrac{1}{2}$
```

答案书写规则：

- 多解列全：`$x = 1$ 或 $x = -1$`（不要只给一个）
- 区间 / 集合：`$x \in (-\infty, 1) \cup (3, +\infty)$`
- 带单位的量写单位；近似值写清精度 `$\approx 1.414$`
- 存在性证明：`存在` + 关键参数（如 `$\xi = 1/2$`）
- 判断类：`收敛` / `发散` / `不可导` 这种结论词直接写，不要绕
- 答案本身复杂时用 `$$` 单独成行也没问题

### 追问时：展开

你说「讲讲思路」「怎么做」「步骤」「为什么」中任意一个，就展开成：

1. **思路**一句话（为什么用这个方法）
2. **步骤**（编号，关键变形给出，中间跳过一眼可得的算术）
3. **验算**（代回 / 边界检查）
4. **易错点**（这题最容易错在哪）

展开时就把答案重新给一次，别让你回头翻。

## 第 3 步 不确定怎么办

- 题干识别可疑 → 先说明「p.88 第 3 题扫描模糊，我按 …… 理解」，再给答案。
- 算不出唯一解（多解未定、条件不足）→ 给通解或参数化解，并写清 `待核对：缺…… 条件`。
- 方法有两种以上 → 默认给最标准的一种；若另一种更短，一句话附注。
- **绝不为了凑一个漂亮答案而编步骤。** 宁可写 `待核对`。
