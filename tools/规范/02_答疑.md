# 02 任务②：基于课本内容答疑

先读 `00_共同约定.md`（公式与输出规范）。本文件只讲流程。

原则：**答案以这本课本为准**。你说「课本上怎么写」，我就去翻原页，不复述记忆里的版本。

---

## 第 1 步 判断要翻多少原文

| 你的问题长这样 | 怎么做 |
| --- | --- |
| 给了页码（「第 45 页那句…」） | 渲 1–3 页看图，直接读原文 |
| 给了章节名 / 定理名，没给页码 | 先定位（`find` 或 `sheet`，见 `01_文本提取.md` 第 1 步），再渲页 |
| 跨章节（「第 3 章和第 5 章这两个定义什么关系」） | 上传整本/整章，用 `ask` 提问，让服务端把相关页一起带进上下文 |
| 纯概念题，不指向具体页（「为什么可导必连续」） | 先按课本口径答，需要佐证时再翻页补页码 |

翻单页（最常用）：

```powershell
$根 = "D:\数学书库"
& "$根\工具\py.cmd" "$根\工具\pdfkit.py" render "<PDF>" --pages 45 --bands 2 --dpi 220
```

然后读 `p0045-1.png`、`p0045-2.png`，用原文回答。

跨章节提问：

```powershell
& "$根\工具\node.cmd" "$根\工具\dsfile.mjs" ask --file-id <已上传的id> --prompt "在 p.40-60 与 p.120-130 中找出关于一致连续的两个定义，逐字引用并说明差别"
```

（`file_id` 从 `缓存\api_files.json` 或 `& "$根\工具\node.cmd" "$根\工具\dsfile.mjs" list` 里拿；没有就先 `upload` 一次。）

## 第 2 步 组织回答

固定四段，按需省略后两段：

1. **直接结论** —— 一两句话把问题答掉，不要铺垫。
2. **课本依据** —— `p.45` 加原文关键句（短引用，公式按 `$`/`$$` 规范写）。
3. **延伸** —— 适用条件、常见易错、与相邻概念的区别。**这一段必须和课本内容区分开**。
4. **不确定处** —— 明确写「课本这一页没有交代」「此处两种读法都通」。

回答里每个事实性论断都要能指回页码；指不回去的，标注是课本外补充。

## 第 3 步 边界

- **超出课本范围**：先给课本内的说法，再单起一句「课本外补充：……」，明确边界。
- **课本本身有错**（笔误、印错符号）：照原文引用，然后标 `> 疑为原书笔误：……`，不要偷偷改。
- **页码找不到 / 图看不清**：说明「p.121 扫描件此处模糊，只能确认到 ……」，不要用推测填空。
- **不写文件**：结论、引用、公式全在对话里。

## 示例骨架

> **结论**：可导必连续，连续不一定可导。
>
> **课本依据**：p.45 原文——「若 $f$ 在 $x_0$ 可导，则 $f$ 在 $x_0$ 连续；反之不然。例如 $y=|x|$ 在 $x=0$ 处连续但不可导。」证明在 p.46 定理 2.3。
>
> **延伸**：连续只保证 $\lim_{x \to x_0} f(x) = f(x_0)$，可导还要求差商极限存在，即左右导数相等；$y=|x|$ 在 $0$ 处左右导数分别为 $-1$ 和 $1$，故不可导。（此段是我补充的，课本 p.45 未展开）
