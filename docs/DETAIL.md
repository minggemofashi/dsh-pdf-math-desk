# 数学工作台

以「书 → 章」为骨架的整页数学工作台。点左侧栏的工作台图标打开：书架列出书，点书卡进入章节页。

## 功能

- **书库**：可添加多个书库；分片目录 `<库根>\分片\<书 id>\`、整本 PDF 放 `<库根>\整本\`；
  分片文件名带页码范围即可（如 `概率论_积分和数学期望_97-138.pdf`），按页序自动编号。
- **书架**：单击选中、双击进入章节；空白处拖拽框选；隐藏书籍、自定义多文件书架（可嵌套）、右键删除书架并释放书。
- **章节会话**：提取 / 答疑 / 习题三组；「＋ 新建」优先进已有会话，上下文接近上限才续开；
  支持导入已有会话、重命名、取消挂载；标题形如 `[书 id c04] 答疑`。
- **产物**：目录 `<库根>\产物\<书 id>\<章号>\`；文本类文件在右侧预览；md 可一键转 PDF（需 Python + TeX Live）；
  产物会话挂在对应 PDF 行下，可折叠、可「另起」。
- **阅读器**：内置 pdf.js，单页/连续、翻页、缩放、页码跳转、键盘操作；右栏预览可开关。
- **清理**：产物删除进 `<库根>\回收站\`；会话归档后工作台不再列出；隐藏书架可整体释放。
- **其他**：设置菜单显示版本号、右侧预览与「非PDF删除」保护开关；底部使用提示可折叠。

## 使用

1. 添加书库（选库根目录），进入书架；
2. 按目录拆分章节 PDF，或直接放整本 PDF；
3. 展开章节 → 打开 PDF 或新建会话；会话自带书名/章名/产物目录上下文。

## 限制

- 仅面向数学书工作流；PDF 阅读器只读，不做标注/笔记；
- Markdown→PDF 需要本机 Python 与 TeX Live（xelatex），插件运行时不依赖；
- 书 id 由目录/文件名推导，添加书库后不要重命名该目录，否则旧会话与产物会对不上；
- 界面只显示本机真实路径；跨机器需重新添加书库。

## 作者想说


开发这一个插件是为了契合我自己学习数学的工作流！

虽然数学看起来已经没有什么前景了，但是学习数学带来的思维上的好处还是很明显的：第一是应用的场景也会对数学能力有进一步的要求，以前可能学个线性代数，凑合能干活就行了，但是现在不学习到抽象代数，可能连如何向AI去问问题，让它干活都不足够；第二是数学教育和美的体会都还在，只是前进、探索的路会有AI走一遍而已。

读数学书则是学习数学的最好方式之一，而为什么不让AI去辅助解答，去给出标答，去辅助笔记呢？有了这个插件，我们不再需要事事与别人讨论，我们拥有至少一条的实现问题的路径，我们不再需要做摘抄这样费时费力的事情！

当然这个插件不是必须的，我早就在用这套工作流了，只是把这套工作流以插件集成的形式体现出来而已，希望大家用的愉快，有问题也可以随时反馈。

## Token 消耗

- 打开书架、展开章节、预览产物、右侧 PDF 预览：不进入模型上下文，不消耗对话 token。
- 新建会话草稿只带一行上下文（书名 / 章名 / PDF / 产物目录），约几百 token 级。
- 会话问答按对话长度计费；「整理提纲」会把该章多个会话再汇总一次。
- 整本 PDF 会话很贵（一次可能几十万 token），只适合小文件/小论文。
- 插件不会自动把 PDF 塞进上下文；AI 需要时会自己读取，读多少取决于它。

## 不能做什么

- 阅读器只读：无标注、高亮、批注、笔记，也不写回 PDF。
- 不做 OCR、不整本拆分；整本 PDF 只作为一本书显示。
- 章节与三种会话的语义面向数学书，不是通用阅读器。
- 书库在本机，跨机器需重新添加；没有全书语义搜索。

## 归档不是删除

会话行的「归档」只把会话移出工作台列表，不会删除会话本身；已归档会话仍保存在 DSH 中，可从 DSH 的归档恢复或在 DSH 里清理。工作台的「清理空会话」只处理没有发过消息的空白会话。

## 平台支持

- **仅支持 Windows 10 / 11（x64）**，且只在这两个系统上验证过。
- macOS / Linux 未适配、未测试：路径分隔符、`py`/`python` 启动器、TeX 检测目录都按 Windows 编写，其他系统上大概率无法正常工作。
- 可选环境：Python 3 + TeX Live（xelatex、ctex）；缺失时「md→PDF」按钮隐藏，其余功能正常。
