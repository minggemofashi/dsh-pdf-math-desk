## 根因与修复核对

1. **根因（表面所有权）成立**：父提交 `268573e:client.js:14116–14117` 中 `.md-question-input` 只有定位与 `min-width`，`.md-question-input input` 只有 `min-width`；插件 CSS 里没有任何自有背景。重命名调用 `client.js:8136` 未给 `KitInput` 传 `className`，外层 `.md-question-input` 拿不到适配层样式。宿主分支的表面来自 `vendor/host-ui.css:73–82` 的 `.Input_wrap { background: var(--dsw-alias-bg-layer-1) }`；回退分支的 `.md-kit-input`（`client.js:13664–13665`）只有 `flex` 与 `font: inherit`，没有背景。因此字段表面不是插件自有，而取决于适配分支/宿主 CSS/浏览器默认值；一旦宿主 CSS 未生效，字段就没有插件可控的背景。
2. **“组件在、表面不在”的路径真实存在**：`loadHostUi`（`client.js:48–82`）只要 `codeResponse.ok` 就执行模块并设置 `hostUi`（`:57`、`:73–75`）；CSS 注入是独立的 `if (cssResponse.ok)`（`:64–72`），CSS 请求失败/为空不会使 `hostUi` 回退。因此宿主 `Input` 组件可能已经渲染，而 `.Input_wrap` 的表面样式没有注入。programmer 未能在本机复现用户看到的确切触发条件（证据 §5 已承认）；这一点列入“未覆盖”，但结构上的脆弱性已由代码独立确认。
3. **修的是根因，不是掩盖**：新样式让 `.md-question-input` 自己拥有 `background`/`border`/`border-radius`（`client.js:14120`），并把适配层自己的盒子拍平（`:14122`），内层 input 透明、无边框（`:14123`）。两条分支都不再依赖 `.Input_wrap` 是否加载；没有用遮罩、延时、强制刷新或特判。`focus-within` 放在外层 wrapper（`:14121`），宿主/回退两分支的 input 聚焦都能触发；被拍平的内层 `.Input_wrap` 不再显示自己的边框。
4. **主题 token 均存在，背景不透明**：本机 DSH 0.2.3-alpha.2 `design-platform.css` 中 `--dsw-alias-bg-base` 浅色为 `--dsw-static-neutral-bluish-00` = `rgb(255,255,255)`、深色为 `--dsw-static-neutral-bluish-950` = `rgb(21,21,23)`（`:177`、`:329`，静态值 `:56`、`:77`）；`--dsw-alias-border-l3` 浅色 `rgba(0,0,0,.12)`、深色 `rgba(255,255,255,.16)`（`:198`、`:350`）；`--dsw-alias-brand-primary` 浅色 `rgb(15,17,21)`、深色 `rgb(249,250,251)`（`:203`、`:355`）；`--dsw-alias-label-primary` 浅色 `rgb(15,17,21)`、深色 `rgb(249,250,251)`（`:259`、`:411`）。四个 token 都在 `body` / `body[data-ds-dark-theme]` 上定义、可继承，背景值不透明；插件已有 `.md-question-name` 等使用同一套 token（`client.js:14107`），不是新依赖。
5. **深/浅色与回退分支覆盖**：深色由 `body[data-ds-dark-theme]` 覆盖全部四个 token，浅色由 `body` 提供；回退分支的 `span.md-kit-input` 匹配 `:14122` 的拍平，内层 `input` 匹配 `:14123` 的规则；宿主分支的 `span.Input_wrap.md-kit-input` 也匹配 `:14122`，因此两分支各自只有外层一层表面。`--dsw-alias-label-primary` 提供与背景匹配的文字色，12px/18px 行高在 24px 高的字段内不会裁切。
6. **布局/可读性**：字段高度从宿主分支原 32px 变为约 24px（18px 行高 + 2×2px 内边距 + 2×1px 边框），宽度因外层缺 `box-sizing` 在回退分支增加约 16px（见 Suggestion 1）；文字对比度由 label-primary 对 bg-base 保证，白底/深底 PDF 上背景仍不透明。没有新增动画、过渡或定位变化；`top/left/z-index/pointer-events` 保持原值。
7. **回退分支透明声明的证据边界**：programmer 的 `.dsh-scratch/u5-probe/probe-before.json` 显示父样式下 wrapper 背景为 `rgba(0,0,0,0)`，但同一次测量里内层 `inputComputedBackground` 是 `rgb(255,255,255)`（jsdom 的 UA 默认值），所以“回退分支内层 input 也没有背景”不能由该证据直接证明；真实 DSH 全局 CSS 是否覆盖它也未在沙箱中加载。修复把表面放到 wrapper，已不依赖这一条；tester 真机验收时不要把该细节当成已证实的复现条件。
