# 全章翻译与双语叠加（设计稿）

> 状态：设计阶段，未实现。目标读者：后续实现者与验收者。

## 1. 目标

1. 在 PDF 视图右上角提供「翻译」开关与语言选择（中→英、英→中）。
2. 对**整章**做翻译：模型识图/OCR 提取为 Markdown，公式保留为 LaTeX，再用 `tools/md2tex.py` 渲染为 PDF。
3. 不展示中间 md 文件；在原文 PDF 下方新增 `_translated.pdf` 供阅读。
4. 双语模式：翻译件与原文件按段落块对齐叠加；可用框选工具露出译文、未框选处不露出；框可保留/删除。
5. 在叠加层之上再加透明标注层（笔、橡皮、文本框），各层独立保存、一起显示。

## 2. 核心决策

### 2.1 块级对齐，而非整页猜配
不采用“先把整章自然排版，再回头对齐”的路线。改为：

1. 用 pdf.js 解析原文每页为**文本块**，记录 `bbox`；
2. 逐块翻译（块就是对齐单位），模型返回结构化结果；
3. 翻译页**按原版式坐标**生成（`textpos`/TikZ + minipage）；
4. 对齐是“构造出来的”，不依赖事后匹配。

### 2.2 双输出
| 输出 | 用途 | 排版 |
| --- | --- | --- |
| `_translated.pdf` | 单独阅读 | 自然流式排版，字号/行距统一 |
| `_translated.overlay.pdf`（缓存，不进产物列表） | 双语叠加 | 每个块绝对定位到原 bbox |

两份共享同一份块翻译结果，**不重复调用 API**。

`_translated.pdf` 也可以从缓存的逐页译文重渲（`POST /mathdesk/rebuild-translated`，v0.49.4）：打开双语/叠加时自动检查，缓存目录里的 `.render-version` 与插件版本一致就跳过，因此改渲染器不用重新付费翻译。

### 2.3 叠加层排版规则（v0.49.3 起为实现口径）
- 块顶部对齐到原 bbox 顶部，`x` 先做同排避让：与同一行的左邻块 x 重叠时右移；
- **有空白就用**：`adjustbox` 的 `max totalheight` 取「本块顶部到下一块顶部」的余量，正文可借用段距，不会压到下一块；
- 仍超出余量才整体等比缩小（不再出现 4pt 小字）；
- 块高度不足以放行间公式时降级为行内公式（`$$…$$` → `$…$`），保住可读字号；
- 文字块允许向右侧空白延伸以减少换行；行间公式保持原块宽度并居中，避免公式被“推走”；
- 模型输出里的 `\(…\)` / `\[…\]` 统一归一化成 `$…$` / `$$…$$`（`md2tex.normalize_math_delimiters`），否则会原样印成乱码。

### 2.4 双语模式两种
1. **并排同步（默认）**：左原文、右 `_translated.pdf`，翻页/滚动联动；实现简单、阅读自然。
2. **叠加框选（实验）**：原文之上叠 `_translated.overlay.pdf`，用矩形“开窗”露出译文；框可保存为 `{page,x,y,w,h}`，可增删；遮罩不依赖对齐精度。

### 2.5 已知限制（必须让用户知道）
- **块翻译失败会退回整页翻译**（v0.70.0 起不再静默）：如果某页的块解析或块级模型返回不可用，该页改用整页译文——双语版不受影响，但叠加层只能整页重排，字号与位置对不上。任务状态会记 `overlayReflowPages`（哪几页是重排），翻译完成提示与阅读器打开叠加时都会说明；重新翻译本章可恢复按块对齐。
- **会漏译**：模型按块返回，偶尔漏块、漏半句或漏整段公式；漏掉的块在叠加层为空、双语版缺这一段。只能重译该章或按块补缓存 md（后者零 token）。
- 叠加层的段落只在自己的 bbox 宽度内换行（v0.49.7 起），下方可借用段距；因此手画框要和块对齐，或直接用「框住本页块」。
- 双语版按原书纸型自然流式排版，**不追求与原文对齐**；逐位置对照请用叠加。
- 块分类是启发式，标题/公式可能判错，只影响调试框与少数块的显示方式。

## 3. 数据模型
### 3.1 块
```json
{
  "id": "b-0012-03",
  "page": 12,
  "bbox": [72, 181, 460, 96],
  "kind": "paragraph",
  "srcMd": "……原文（可选）",
  "dstMd": "……译文，含 $...$ / $$...$$",
  "overflow": false
}
```
`kind`: `heading` / `paragraph` / `formula` / `figure` / `caption` / `list`。

### 3.2 章节翻译清单
```json
{
  "chapter": "c01",
  "source": "概率论_c01_…….pdf",
  "lang": "zh-en",
  "createdAt": 0,
  "pages": 40,
  "blocks": [],
  "files": {
    "reading": "……_translated.pdf",
    "overlay": ".mathdesk-cache/……overlay.pdf"
  }
}
```
存于 `<库根>\产物\<书 id>\<cNN>\` 旁的私有缓存目录，md 不进入产物列表。

### 3.3 双语遮罩与标注
```json
{
  "masks": [{ "page": 3, "x": 120, "y": 300, "w": 380, "h": 140 }],
  "strokes": [{ "page": 3, "color": "#000", "width": 2, "points": [[x,y], …] }],
  "texts": [{ "page": 3, "x": 100, "y": 200, "w": 300, "h": 40, "text": "…", "size": 14 }]
}
```
按「书/章/页」存 sidecar JSON，各层独立、一起渲染。

## 4. 处理流程

### 4.1 解析
- pdf.js `getTextContent()` → 按 y/x 合并行 → 按行距与缩进合并段落；
- 标题按字号与字重识别；
- 公式/图片区域单独成块（不做流内拆分）；
- 双栏、跨页段落暂不支持（标记为 `unsupported`，整页回退为“整页处理”）。

### 4.2 翻译
- 每块发送：块的局部截图（或带坐标的文本）+ 指令；
- 指令要求：只翻译自然语言，公式原样保留为 `$...$` / `$$...$$`，返回 `{id, md}`；
- 校验：`$` 配对、`\begin/\end` 配对、块 id 完整；失败重试 1 次，再失败标记 `failed`；
- 视觉模型：`deepseek-flash` 图片输入（约 1024 token/图），或文本层 + 文本模型以省钱；按配置切换。

### 4.3 渲染
- 阅读版：所有块 md 按顺序拼接 → 现有 `md2tex.py`；
- 叠加版：每块 md 生成 `textpos` 绝对定位片段，按 bbox 排版；必要时缩字号；
- 奇数页/偶数页边距不同，坐标需换算到 LaTeX 页面坐标系（A4/Letter 自适应）；
- 生成后缓存；重复翻译前先查缓存。

### 4.4 展示与交互
- 原文 PDF 下方列出 `_translated.pdf`，可打开阅读；
- 双语开关：并排 / 叠加 / 关闭；
- 叠加模式工具条：框选、删除框、清空、保存；画笔、橡皮、文本框；
- 框选/标注改动即时写入 sidecar（防抖）。

## 5. 性能

- 只渲染当前可见页；其他页 canvas 置空释放；
- 双语叠加：原页 1 个 canvas + 叠加页 1 个 canvas + 标注 1 个 canvas；
- 标注用矢量数据，单页笔迹上千条仍可实时；
- 翻译是离线任务，逐块/逐页进行，进度可见，可取消；
- 缓存编译结果，避免重复编译/重复调用。

## 6. 成本与限制

- 块级翻译：一页约 3–8 块，一章几十页 → 几十到几百次调用；
- 单图约 1024 token 上限，长页需分块截图；
- 公式可能被模型改写错误：必须校验并允许手动修正块译文后重渲染；
- 对齐边界：段落起点对齐，行数不做逐行重合；双栏/跨页不支持；
- 仅 Windows（见 README 平台说明）。

## 7. 配置

```yaml
translation:
  provider: deepseek        # 官方 API
  model: deepseek-flash
  source: vision | text     # 识图或文本层
  maxBlocksPerPage: 12
  fontShrinkMin: 0.75
  overlay: true             # 是否生成叠加版
```

API Key 走插件设置，不写入仓库与日志。

## 8. 实施阶段

| 阶段 | 内容 | 验收 |
| --- | --- | --- |
| P0 | 块解析 + bbox 导出原型（不调用 API） | 一章 PDF 能输出块清单，坐标正确 |
| P1 | 逐块翻译 + 阅读版 `_translated.pdf` | 公式保留、页面可读、按钮/语言/进度可用 |
| P2 | 叠加版 + 并排模式 | 叠加页与原页 1:1，框选露底可用，框可保存 |
| P3 | 标注层（笔/橡皮/文本框） | 矢量保存、页面切换不丢、性能可接受 |
| P4 | 溢出微调、双栏/跨页兜底 | 常见教材章节通过 |
