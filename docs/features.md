# 功能全貌（features）

> **维护者：队长/用户**，仅 major 版本核对；minor/patch 由 ci 在 CHANGELOG 中写清。
> 本文件描述“项目现在能做什么”，不是路线图。计划中、未合入的能力不写进来。
>
> **当前基线：v1.4.0（2026-11-24）。** 此初始版本由搭建会话从现有 README / CHANGELOG / 代码边界转录，**不是一次完整的端到端功能审计**；下一次 major 由 feature-inventory 全量复核。

## 状态标记

- **稳定**：作者日常使用，未发现阻断性大问题；仍有交互小问题会持续打磨。
- **比较稳定**：可作为日常流程使用，但仍有已知限制。
- **实验**：不建议作为稳定主流程；问题较多，对外必须保留“实验”标记。
- **未实测**：入口存在，但端到端恢复/使用尚未验证，不能保证可用，不能当唯一备份。

## 当前能力

| 模块 | 能做什么 | 状态 | 已知限制/说明 |
| --- | --- | --- | --- |
| 书库 | 配置多个书库；支持 `分片/<书 id>/`（一章一个 PDF）和 `整本/`；首次打开进入书库页，不自动生成书库；书库卡片可「进入书库」「打开书库目录」 | 稳定 | 不做自动章节识别；拆书由用户或外部工具完成 |
| 书架 | 封面、作者、章节数；单击选中、双击进书；空白拖拽框选；分组、隐藏、回收站；封面图带 ETag（不再每次重下） | 稳定 | 旧数据与重名文件有兼容逻辑，仍需回归测试 |
| 章节 | 提取 / 答疑 / 习题三类会话；导入已有会话、重命名、取消挂载；产物按章归档 | 稳定 | 章节文本只读一次；扫描件无法提取文本时回退普通会话 |
| 阅读器 | 内置 pdf.js；单页/连续、适应宽度、缩放、页码跳转、键盘翻页；右侧可开同章预览；页面位图缓存 2–8 页可调 | 稳定 | Windows 优先；客户端改动需重启 DSH，不能热更新 |
| 画布 | 页面 + 页外可写区域；手写、文本、形状、框选、疑问标记；笔压、手绘风格、撤销/重做 | 稳定 | 页外只画笔记，不渲染相邻页 PDF；单页/连续共享标注平面 |
| 选择与编辑 | 选择工具框选多个元素、拖动移动、Backspace/Delete 删除、形状四角缩放、文本编辑 | 稳定 | 一次撤销应整体还原；快捷键可在设置里改 |
| 双语对照 | 整章翻译后左右并排；两栏可各自滚动/缩放；各有独立标注层 | 比较稳定 | 双语两栏页码不同步（v0.72.5 已确认）；译文栏笔记独立保存 |
| 覆盖层翻译 | 在原文页框选区域，框内显示译文；结果保存在本章 sidecar，可导出/导入 | 实验 | **bug 较多，不建议当稳定主流程**；不承诺像素级/逐行对齐 |
| 问答与会话 | 章节会话自带书名/章名/PDF/阅读位置/产物目录；可切苏格拉底式答疑人格；整章共享前缀；**思考模式**（日常=简短、高质=可长篇推导）与**可编辑的风格提示词** | 稳定 | 整本书会话成本高；按章拆分更适合；思考深度由所选模型决定 |
| 附件与产物 | 章节内添加 PDF/图片附件；PPT 可转 PDF；文本类产物可预览；Markdown 可生成打印页 | 稳定 | PPT 转换依赖本机 PowerPoint 或 LibreOffice；DOCX/DOC 走 DSH 文档预览 |
| 导入 | 一个管线收口：PDF/md/txt、书籍包 ZIP、迁移包 ZIP；文件头校验、同内容去重、统一 `-2` 命名、流式解包、原子落盘、统一报告；导入向导按书勾选；`.lnk` 按目标 PDF 导入 | 稳定 | 旧 `/import`、`/library-import` 已删除（v1.5 之后的兼容期结束）；zip64/加密包明确拒绝 |
| 导出与迁移 | 整机迁移包、书库包、PDF 包（均不含不该带的东西）；后台打包、打包记录（下载/打开位置/删除）；导入前快照与 sha256 校验 | 稳定（2026-11-26 实测） | 迁移包不含书籍 PDF 与凭据；打包体积大头是 DSH 会话记录 |
| 拆分工具 | 按页拆分整本 PDF：三处入口共用面板，缩略图每行 4 页 + 竖向虚线剪刀，范围与文件名实时预览，拆点按书记住 | 稳定 | 依赖 `tools/split_pdf.py`；结果写进 `分片/<书id>/` |
| 存储与治理 | 「存储占用」分区统计；保留期清理（回收站/译文缓存/任务状态，均需确认）；重复 PDF 报告（只报告）；清空回收站 | 稳定 | 只删可重建物；永不自动删 PDF、标注、产物 |
| 设置 | 阅读、模式、快捷键、环境、数据、AI 模型、关于；GitHub 反馈；手写字体；思考模式；数据位置只读展示 | 稳定 | 缺 Python/TeX/API Key 时给出说明和入口，不静默失败 |
| 环境检查 | 设置页检查 Python 3、TeX Live、API Key；缺环境时阻止依赖操作并给下载入口 | 稳定 | 不是所有缺失环境都会阻断阅读；仅阻断翻译/转 PDF 等对应操作 |
| 性能与路由 | PDF 路由支持 Range / ETag / 304、并发 GET 去重；固定边界测量按帧合并；启动不预加载 pdf.js | 稳定 | 具体性能数据需在真实书库复验，不能只凭单元测试 |

## 平台与隐私

- **平台**：Windows 10 / 11（x64）；macOS / Linux 未适配、未测试。
- **DSH**：最低版本见 `package.json` 的 `engines.dsh`。
- **数据位置**：书库与插件设置在 `~/.dsh/pdfdesk/`；标注/疑问/附件/缓存在书库内 `.pdfdesk/`；会话由 DSH 保存在本机。
- **隐私**：不收集遥测、不需要账号、不上传书库；问答与整章翻译只会在用户发起时调用已配置的模型 API。
- **凭据**：迁移包不包含书籍 PDF 与凭据；UI 不显示 API Key。

## 明确不在当前功能内

- 自动识别章节并拆书；
- OCR（扫描件只支持打开/标注，不支持自动识别文字）；
- macOS / Linux 适配；
- 云同步、账号体系、遥测；
- 将覆盖层翻译或整机迁移包作为稳定/可完全依赖的能力；
- 按时间筛选迁移包里的会话（用户 2026-11-26 明确不做，只标注体积）；
- 开发版侧栏标签（用户 2026-11-26 明确取消，用两个 DSH 档区分即可）；
- ZIP64（>4 GB 单文件或 >65535 条目）与加密 ZIP 的导入（明确报错，不静默失败）。

## 维护规则

- 仅 major 版本由 feature-inventory 全量更新；minor/patch 的事实变化由 CHANGELOG 承载，避免每版全量盘点。
- 新增能力必须有已合入证据；实验/未实测状态不能因为“快发布了”而改成稳定。
- 移除/改名功能要保留历史说明，不能静默消失。
- README 与 `docs/features.md` 不一致时，以代码与测试证据为准，先修正本文件，再向用户提 README 更新提案。
