# 路线图：翻译与双语能力

原则：**一个功能一个功能做**，每个里程碑都能单独验收，避免“翻译做完了再回头改对齐”。

测试样例：`samples/test/serre_c01_p2-3.pdf`（Serre《有限群的线性表示论》第一章第 2–3 页，两页，含公式与定理块）。
成本控制：P0–P2 只在这两页上验证，不跑整章；整章翻译最后做。

## M1 — 块解析与调试可视化（零 API 费用）

**交付**
- Host/Client 用 pdf.js 解析每页文本项，合并为块（标题/段落/公式/图）；
- 每块记录 `id / page / bbox / kind / 文本`；
- 阅读器加一个隐藏的「调试：块边框」开关，在原 PDF 上画出块框，便于肉眼验证；
- 可导出块清单 JSON（控制台或临时下载）。

**验收**
- 两页样例中，标题、定理、公式、段落能被正确切块；
- 框与文字位置吻合，无大块缺失或重复；
- 不调用任何 API。

**风险**：pdf.js 文本项合并参数（行距阈值、缩进）需要按两页调参。

## M2 — 单页翻译（阅读版）

**交付**
- 设置里填 DeepSeek API Key（或复用 DSH 凭据）；
- 选中两页 → 「翻译本页」按钮 → 每块调用 `deepseek-flash` 视觉/文本；
- 返回 `{id, md}`，校验公式；
- 用 `md2tex.py` 渲染为 `_translated.pdf`（自然排版），在原文下方提供打开；
- 不显示 md 文件。

**验收**
- 两页译文可读，公式与定理编号保留；
- 失败块可单独重试；
- 费用可控（两页调用次数、token 有日志）。

## M3 — 叠加版与并排模式

**交付**
- 生成 `_translated.overlay.pdf`：块按原 bbox 绝对定位（textpos + minipage）；
- 双语模式默认「并排同步」，翻页/滚动联动；
- 「叠加」开关：原页上叠翻译页，整页可见；
- 叠加版溢出块记录 `overflow`。

**验收**
- 两页叠加时，段落起点与原文一致，无大面积错位；
- 溢出块被标记，界面能提示；
- 并排模式阅读自然。

## M4 — 框选露底

**交付**
- 叠加模式下工具条：框选工具、删除框、清空；
- 矩形用 `clip-path` 开窗，露出译文；
- 框数据按页存 sidecar JSON，可保存/恢复；
- **两种框选方式**（先用自由矩形，再补按段落）：
  1. 自由矩形：鼠标拖拽，任意大小/位置；
  2. 按段落：点选 M1 解析出的块，自动生成覆盖该块的框（虚线预览，可再拖动微调）。

**验收**
- 画框/删框即时生效；重启/刷新后框仍在；
- 未框选区域不露译文；
- 自由框与段落框都能保存、删除；
- 框不依赖段落对齐精度。

## M5 — 标注层（笔 / 橡皮 / 文本框）

**交付**
- 透明画布叠在双语层上；
- 笔：颜色/粗细；橡皮：按笔画或点擦；文本框：输入、拖动、删除；
- 矢量存储，与遮罩分开文件、一起渲染。

**验收**
- 翻页、缩放后笔迹位置正确；
- 单页上百笔顺滑；
- 数据只存矢量，不存位图。

## M6 — 全章翻译（按钮 + 语言 + 进度）

**交付**
- PDF 右上角「翻译」开关 + 语言选择（中→英 / 英→中）；
- 整章任务队列：逐页/逐块，进度可见、可取消；
- 输出 `_translated.pdf` 于原 PDF 下方；缓存避免重复计费；
- 失败重试与断点续跑。

**验收**
- 一章完整跑通；
- 中断后能续跑；
- 产物列表只出现 `_translated.pdf`，不出现 md。

## M7 — 兜底与打磨

- 溢出块手动微调（每页 dx/dy/缩放）；
- 双栏、跨页段落识别失败时整页回退；
- 性能：只渲染可见页，内存峰值可控；
- 文档、截图、示例更新。

## 双视图一致（右侧预览）

翻译、双语叠加、框选露底、标注，**在整页阅读器和右侧预览里都要可用**，不是只做阅读器。

实现要求：
- 抽一个共享的 PDF 视图组件，整页阅读器与右侧预览只是尺寸/工具条不同，渲染与坐标逻辑同一套；
- 遮罩框、笔迹、文本框坐标按**页面归一化坐标（0–1）**存储，缩放/窄栏都不漂移；
- 右侧预览空间小：框选、画笔默认收起为图标工具，展开后操作；双击可切到整页阅读器继续编辑；
- 翻译入口在预览里也提供「翻译本页」，整章翻译仍放整页阅读器；
- 两个视图共享同一份 sidecar 数据，改动即时同步（同一本书/章/页）。

验收：同一页在阅读器里画框/写标注，右侧预览打开同一页时能看到；反之亦然。

## 里程碑依赖

```
M1 → M2 → M3 → M4 → M5
              ↘ M6 → M7
```

M2 之前不写界面翻译开关；M3 之前不做框选；M4/M5 不依赖 M6。
