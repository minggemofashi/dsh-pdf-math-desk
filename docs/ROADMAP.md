# 路线图：翻译与双语能力

原则：**一个功能一个功能做**，每个里程碑能单独验收，做完再改下一个；每个里程碑写清「交付 / 验收 / 不做什么」，避免跑偏。

测试样例：`samples/test/serre_c01_p2-3.pdf`（Serre 第一章第 2–3 页，含标题、段落、公式）。
成本控制：只在两页样例上验证细节，整章翻译最后跑。

## M3 — 双语与叠加

### M3-2a 页级叠加 + 自由框（下一步）
**交付**
- 阅读器（单页模式）新增「叠加」开关；
- 底：原文当前页；上：译文同页码，默认隐藏；
- 拖拽画矩形，矩形内用 `clip-path` 露出译文；点框删除；「清空」；
- 框按 `book/code/page` 存 localStorage，重开仍在；
- 译文页不存在时提示“本页无译文”。

**验收**
- 框内显示译文、框外不显示；
- 框可删除、可恢复；翻页后各页框独立；
- 不依赖段落对齐。

**不做**：不做按段落选框，不生成新 PDF。

### M3-2b 按段落框
**交付**
- 点「按段落」后，点击 M1 的块生成覆盖框，可拖动微调；
- 与自由框共存。

**验收**：段落框位置贴合文字；与自由框可同时保存。

**不做**：不追求公式块完整识别。

### M3-2c 按原 bbox 的叠加 PDF（实验）
**交付**
- 生成 `_overlay.pdf`：每页按原 bbox 绝对定位（textpos+minipage），页数与原文 1:1；
- 溢出块缩字号并记录；
- 叠加模式改用该 PDF。

**验收**：段落起点与原文一致；溢出块可见提示；并排模式不受影响。

**不做**：不承诺像素级/逐行对齐；双栏、跨页段落走整页回退。

## M4 — 标注层（笔 / 橡皮 / 文本框）

**交付**
- 透明画布叠在双语层之上；
- 笔（颜色/粗细）、橡皮（按笔画或点擦）、文本框（输入/拖动/删除）；
- 矢量存储（笔画点集、文本坐标），与遮罩分开文件、一起渲染；
- 阅读器与右侧预览都能用（归一化坐标）。

**验收**：翻页/缩放后位置正确；单页上百笔顺滑；与遮罩互不影响。

**不做**：不做墨迹平滑/压感，不做导出图片。

---

## M5 — 整章翻译工程化

**交付**
- 中断续跑：任务记录已完成页，重启后继续；
- 单页失败重试（不整章重来）；
- 每章语言与状态记录；预计 token/费用日志；
- 「翻译本章」在右侧预览也可触发。

**验收**：中途关闭 DSH 后继续；单页失败只重试该页；同一章重复翻译有缓存提示。

---

## M6 — 导出与分享

**交付**
- 导出当前页/整章：原文 + 译文 + 框选 + 标注合成，输出 PDF；
- 或导出 sidecar JSON，供其他设备导入。

**验收**：导出的 PDF 打开正常；标注位置与阅读器一致。
