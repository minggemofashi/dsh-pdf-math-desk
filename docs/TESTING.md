# 测试清单（Windows 干净环境）

本插件目前只声明支持 **Windows 10 / 11（x64）**。Mac/Linux 未适配。
下面用 **VirtualBox + Windows 10 ISO** 做干净环境验收（家庭版也能用）。

## 一、准备

1. 安装 [VirtualBox 7.x](https://www.virtualbox.org/wiki/Downloads)（Windows hosts）。
2. 可选：同页下载 **Extension Pack**，共享文件夹/剪贴板更顺。
3. 下载 **Windows 10 22H2 ISO**（微软官网“下载 Windows 10 磁盘映像”，约 5–6 GB）。
4. 确认主机已开虚拟化：任务管理器 → 性能 → CPU → “虚拟化：已启用”。

## 二、建虚拟机

| 项目 | 建议值 |
| --- | --- |
| 类型 | Windows 10 (64-bit) |
| 内存 | 4 GB（主机 16 GB 可给 8 GB） |
| CPU | 2 核 |
| 磁盘 | 64 GB，动态分配 |
| 网络 | NAT（GitHub 慢就在 VM 里配代理） |

装好 Windows 后，装 **DSH**，再装增强功能（剪贴板、共享文件夹）。
关机 → 右键虚拟机 → **生成快照**，命名 `DSH-clean`。之后每轮测试都从该快照恢复。

## 三、测试矩阵

每轮开始前：恢复 `DSH-clean` 快照。

### 1. 干净安装
- [ ] 把插件 zip 通过共享文件夹放进 VM；
- [ ] 插件管理 → 安装该 zip；
- [ ] 首次打开进入**书库页**（不是“读取书目失败”）；
- [ ] 顶栏有 GitHub、设置、清理空会话、刷新（不再有检查更新）。

### 2. 缺环境
- [ ] VM 不装 Python、不装 TeX；
- [ ] 产物区 md 的**「转 PDF」按钮不存在**；
- [ ] 设置页「环境」显示 Python 3 / TeX Live 各自的“未安装”，并给出两个下载按钮（约 25 MB / 约 5 GB）；
- [ ] 读书、开会话、预览 md 均正常。

### 3. 设置页
- [ ] ⚙ 打开独立设置页（弹窗），顶部四个标签：阅读 / 快捷键 / 环境 / 关于；
- [ ] 「检查更新」在「关于」里，点击有反馈；
- [ ] 「阅读」里“右侧预览”“非PDF删除”可切换并持久化，并说明笔记镜像目录；
- [ ] 「快捷键」里每一行都能「录制」：按新键后立刻生效，Esc 取消录制；「清除」「恢复默认」「全部清空」正常；
- [ ] 回到阅读器验证：默认键（←/→、PgUp/PgDn、↑/↓、Home、+/-、Esc）与改动后的键都按设置工作，文本框里打字不触发翻页；
- [ ] × / 点遮罩可关闭。

### 4. 交互
- [ ] 书卡单击选中：描边完整、不被裁切；
- [ ] 双击进章节；章节展开/收起；
- [ ] 产物预览、pdf.js 阅读、翻页/缩放；
- [ ] 单击书卡后快速点章节不会误触（防抖）。

### 4b. 右侧会话预览（v0.61.0）
- [ ] 阅读器里点「答疑」进入会话：右栏标签页标题是「书名 · 章代码」，里面是**同款阅读器**（不是 DSH 原来的 PDF 预览）；
- [ ] 阅读器翻到第 5 页 → 右栏跟到第 5 页；右栏翻页 → 阅读器跟到同页且不抖动；
- [ ] 阅读器放大 → 右栏百分比一样（栏窄就横向滚动）；右栏自己缩放不影响阅读器；
- [ ] 单页/连续切换两侧同步；
- [ ] 阅读器画一笔 → 右栏约 0.3 秒内出现同一笔，右栏不能编辑；
- [ ] 阅读器打开「叠加」画一个框 → 右栏同一位置出现框，框内是译文；框层不能拖动/删除；
- [ ] 拖动侧栏宽度、缩放浏览器窗口 → 右栏自动重新按栏宽排版，不需要点「适应宽度」；
- [ ] 右键预览任意位置、或点工具条 `⋯` → 弹出同一个菜单；跳页/缩放/单页连续/重新加载/关闭预览都在里面且置灰、打勾正确；
- [ ] 右栏点笔 → 在页面上画一笔 → 回阅读器同一页能看到；反过来阅读器画的笔右侧也能看到；
- [ ] 右栏点擦 → 点/划过笔画能删掉；菜单「清除本页标注」整页清空，阅读器同步清空；
- [ ] 右栏点框选 → 拖一个框，框内出现译文；**拖动框体可移动、拖八个把手可改大小、右键删除**；撤销后框回来，重做再删掉；菜单「清空本页框选」整页去掉，阅读器同步；
- [ ] 阅读器点文本框 → 点页面就地出现输入框 → 输入中文，Enter 保存（Shift+Enter 换行、Esc 取消）；保存后阅读器与右栏都能看到这段文字；
- [ ] 切到「双语」：左右两栏都能点笔/擦/文本框并落笔（不跳回单页）；写在译文栏的笔记切回单页/译文仍在同一页；
- [ ] 切到「连续」：滚动到第 3 页点笔写字，图层跟着当前页走；再翻到第 4 页写的笔记不会跑到第 3 页；
- [ ] 阅读器打开「叠加」画两个框：拖动框体移动、拖角改大小都只保存最后的位置；右键删掉一个 → 点 ↶ 撤销回来 → 点 ↷ 重做再删掉；
- [ ] 画三笔、每笔后点 ↶：逐笔回退；↷ 逐笔恢复；新画一笔后 ↷ 变灰（redo 分支被丢弃）；
- [ ] 在右栏画一笔，阅读器点 ↶ 能撤回这一笔；阅读器画一笔，右栏点 ↶ 也能撤回（两栏共用一个撤销栈）；
- [ ] 双击一个已有的文本框 → 内容进入编辑；清空后保存，框消失；
- [ ] 右栏点文本框 → 点页面输入 → 阅读器同一页出现；右栏点已有的框也能改；
- [ ] 右栏点页码 → 就地变成输入框，Enter 跳到该页、Esc 取消；菜单「跳页…」也能打开它；
- [ ] 右键 → 跳到会话 ▸ 提取：已有会话直接跳过去；还没有时显示「＋ 提取」，点了会在工作台新建并跳转；
- [ ] 右栏切到连续模式：四个工具仍可用，框选画在当前页；
- [ ] 一页画 5~10 个框：框内译文正常，任务管理器里内存不随框数暴涨（整页只栅格化一次）；
- [ ] 一本 200+ 章的书：先只显示 40 章，滚到底自动追加（或点「再显示 N 章」），滚动不卡；
- [ ] 右键 → 隐藏工具条：预览只剩页面；鼠标移到右上角出现 `⋯`，点它或右键可「显示工具条」；重开标签后选择仍保留；
- [ ] 画几笔后去 `<库根>\.mathdesk\annotations\<书>\<章>.json` 能看到同一份数据；清掉浏览器站点数据再打开该章，笔画自动回来；
- [ ] 更新前的旧笔记（只在 localStorage 里的）第一次打开章节后，会出现在上面那个 json 里，且页面上的笔画没有被改动；
- [ ] 菜单里勾「跟随阅读器缩放」→ 阅读器放大时右栏跟着变；再勾「自动适应栏宽」→ 右栏回到跟随栏宽；
- [ ] 翻译/补译完成 → 右栏自动换到新译文，框内文字也跟着换；
- [ ] 整页翻译（没有块缓存）的章节打开「叠加」→ 出现「整页重排、对不齐」的说明与「按段落重建（零 token）」按钮；点它转十几秒后叠加层重建为 1:1 页数，译文落到原段落位置（近似对齐，个别段落偏小），再次打开不报整页重排；
- [ ] 「在工作台打开」跳回阅读器同一页（换章时会先切到那本书）；
- [ ] 关掉右栏标签，阅读器不受影响；再次点会话按钮可重新打开；
- [ ] 右栏服务缺失时（极端情况）退回 DSH 原生文件预览，不报错。

### 5. 卸载与重装
- [ ] 卸载插件；
- [ ] 从 GitHub（或 Release zip）重新安装；
- [ ] 书库列表、书架、会话标题仍在（数据在 `~/.dsh/mathdesk/`）。

### 6. 异常路径
- [ ] 删除书库目录后打开：提示“读取书目失败 / 请确认目录”，可重试，不崩溃；
- [ ] 删除产物文件后点预览：提示“文件不存在”，可「重新读取」；
- [ ] 归档会话后，工作台列表不再显示，DSH 归档里仍在。

## 四、通过标准
- 以上全部勾选；
- 无红屏/白屏、无控制台报错；
- 首启不需要用户手动改任何配置。

- 截图与路径均为本机示例；
- 测试完成后可把快照导出为 OVA，发给其他人复现。
